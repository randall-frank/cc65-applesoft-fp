Detailed Description

A collection of useful numbers that are included in the package.

These read-only constants may be passed to asfp_mem2fac() to initialize the FAC or passed to math functions like asfp_mem_mul_fac().

An example using two constants to compute PI:

asfp_mem2fac(&AS_CONST_two_pi); // FAC=2PI
asfp_mem_mul_fac(&AS_CONST_half); // FAC=0.5*2PI
printf("Computed PI: %s\n", asfp_fac2str());
